# Security & Threat Model — VayuMitra

VayuMitra processes live Open-Meteo environmental telemetry, household sensitivity profiles, user questions, and optional user-uploaded room/sky photos. This document summarizes the application's threat model and defense-in-depth controls.

## 1. Threat Model & Implemented Controls

| Asset / Surface | Threat | Control Implemented |
| :--- | :--- | :--- |
| **`GEMINI_API_KEY`** | Key leakage to client bundle, logs, or missing config silent degradation | Strictly server-side (`process.env.GEMINI_API_KEY` via `requireGeminiApiKey()` in `server/gemini.ts`, re-exported from `server.ts`). Startup fails fast with `ConfigError` when missing or still set to `'MY_GEMINI_API_KEY'`. Never prefixed with `VITE_`; `.env*` ignored in `.gitignore`; `.env.example` stores placeholders only. |
| **User Photos (`/api/photo-check`)** | GPS/EXIF metadata leakage, MIME spoofing, oversized uploads, photo retention | Client validates MIME (`image/jpeg`, `image/png`, `image/webp`) and `<= 4 MB`, redraws onto an offscreen `<canvas>` (`src/lib/vision/exifStrip.ts`) to strip all EXIF/GPS/XMP headers locally, and revokes blob URLs on unmount/reset (`src/components/PhotoCheckCard.tsx`, `src/components/assistant/PhotoSubcomponents.tsx`). Server (`server/routes/photoCheck.ts`) re-validates `.strict()` Zod schema, base64 charset, `<= 4 MB` decoded size, and **actual binary magic bytes** (`FF D8 FF` JPEG, `89 50 4E 47` PNG, `RIFF....WEBP` WebP) under a route-scoped `6mb` limit, never stores or caches photos, and never logs image payloads. |
| **API Inputs (`/api/*`)** | Type confusion, coordinate spoofing, oversized payloads, unknown fields | Every POST route (`server/routes/advice.ts`, `server/routes/ask.ts`, `server/routes/photoCheck.ts`) enforces `.strict()` Zod schemas (`AdviceRequestSchema`, `AskRequestSchema`, `PhotoCheckRequestSchema`), India geographic bounds (`latitude 6..37.6`, `longitude 68..97.5`), `cityName` regex (`1..80` chars), `question` (`2..300` chars), strict enums, `<`/`>`/control-character sanitization (`sanitizeUserText` in `src/lib/shared/domain.ts`), and `64kb` JSON parser limit on text routes (`server/middleware.ts`). |
| **Prompt Injection & XSS** | Untrusted `cityName`, `question`, or `sceneContext` overriding system rules or injecting HTML | All untrusted user inputs are wrapped in `<untrusted_input name="...">...</untrusted_input>` delimiters (`server/prompts.ts`) with explicit system-instruction overrides to treat tagged content strictly as data. Gemini outputs are constrained by `responseSchema`, validated server-side with Zod, and rendered exclusively via escaped React JSX text nodes (`dangerouslySetInnerHTML` is never used). |
| **CORS & Browser Surface** | Cross-origin abuse, XSS, clickjacking, MIME sniffing, sensor misuse | Origin-locked CORS on `/api/*` (`server/middleware.ts`) rejects foreign origins with HTTP `403`. Every response sets per-request cryptographic nonce CSP (`default-src 'self'`, `script-src 'self' 'nonce-...'`, `style-src 'self' 'nonce-...' https://fonts.googleapis.com`, `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, `frame-ancestors 'none'`, zero `'unsafe-inline'`, zero `'unsafe-eval'`), `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, and `Permissions-Policy: camera=(self), microphone=(), geolocation=()`. `x-powered-by` is disabled and nonces are injected into HTML via `server/frontend.ts`. |
| **Abuse, Hang & Quota Exhaustion** | Automated flooding, slow upstream hangs | Per-IP sliding-window rate limits (`server/rateLimiter.ts`: `20/min` advice, `12/min` ask, `6/min` photo-check) returning HTTP `429` + `Retry-After`, bounded 10-minute caches with in-flight deduplication (`server/cache.ts`, `APP_CONFIG.cacheTtlMs`), `AbortController` upstream/client timeouts (`server/gemini.ts`, `src/lib/api/httpClient.ts`), and deterministic bilingual fallbacks. |
| **Operational Logging & Errors** | Secret/PII/prompt leakage in logs or stack traces in API errors | `logStructured` (`server/logger.ts`) outputs JSON logs and automatically redacts keys matching `/key\|token\|secret\|password\|auth\|imagebase64\|prompt\|question/i`. Central error middleware (`server/middleware.ts`) assigns a `correlationId` and never exposes stack traces or internal errors to clients. |
| **Supply Chain** | Vulnerable npm packages or drifting transitive versions | Exact dependency versions pinned in `package.json`, lockfile verified in `package-lock.json`, and `npm audit --omit=dev --audit-level=high` enforced in CI (`.github/workflows/ci.yml`). |

## 2. Verification & PoC Checks

All security and resilience invariants below execute deterministically in automated CI without calling live external APIs:

1. **Missing Key Fail-Fast (`src/lib/__tests__/apiRoutes.test.ts`)**: `requireGeminiApiKey({})` and `createExpressApp()` without `GEMINI_API_KEY` throw `ConfigError` (`server/gemini.ts`, re-exported by `server.ts`).
2. **Magic-Byte Spoofing & Unknown Fields Rejection (`src/lib/__tests__/apiRoutes.test.ts`)**: Sending `'A'.repeat(64)` labeled `image/jpeg` or an unknown JSON key to `/api/advice` returns HTTP `400`; bodies exceeding `64kb` return HTTP `413`; malformed JSON returns generic HTTP `400` with `correlationId` and zero stack traces.
3. **Nonce CSP & Foreign CORS Enforcement (`src/lib/__tests__/apiRoutes.test.ts`)**: `GET /api/health` confirms unique `'nonce-...'` without `'unsafe-inline'`/`'unsafe-eval'`, `frame-ancestors 'none'`, and HTTP `403` on `Origin: https://evil.example`. `GET /` (`server/frontend.ts`) injects matching nonces into HTML `<script>`, `<style>`, and `<meta property="csp-nonce">` tags.
4. **Rate Limiting & Quota Failover (`src/lib/__tests__/apiRoutes.test.ts`)**: Exceeding per-route IP quotas returns HTTP `429` with `Retry-After`; `429 RESOURCE_EXHAUSTED` from `gemini-4-hydrogen` activates cooldown in `server/gemini.ts` and seamlessly fails over to `gemini-3.1-flash-lite`.
5. **Offline Snapshot Recovery, ErrorBoundary & Accessibility (`src/lib/__tests__/uiComponents.test.tsx`)**: Open-Meteo `503` triggers fallback to the last saved city snapshot with an `"Offline"` badge and live Retry recovery; `<html lang>` switches `"en"` <-> `"hi"`; `jest-axe` reports `0` WCAG violations across all cards and modals.
